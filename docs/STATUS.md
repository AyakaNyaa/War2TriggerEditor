# Состояние первой тестовой сборки

План одобрен пользователем. Реализация начата 9 ноября 2026.
Все исключения из ограничения 500 строк отклонены пользователем.

## Готово для технической проверки

- Workspace из contracts, app-api, format-pud, format-w2tr, trigger-engine, storage.
- Windows-оболочка Tauri и встроенный React frontend.
- Строгие границы звезды и общий API для UI/CLI.
- Rust OpenAPI → небольшие TypeScript DTO.
- Побайтные roundtrip и точечные изменения всех 14 реальных примеров.
- Проверка повреждённых форматов, неизвестные данные только для просмотра.
- Редактирование, предпросмотр, история, сохранение и резервные копии.
- Восстановление файловых бэкапов и сеансов после перезапуска.
- RU/EN, именованные основные поля, списки юнитов/игроков, изменение панели.
- Compact lock-файлы и схемы Tauri без потери их данных, с проверкой 500 строк.

## Что не объявляется завершённым

- Игровая приёмка: нужны точная сборка War2Combat/War2Mod и запуск сценариев.
- Полная семантическая валидация каждой команды под конкретную версию игры.
- Удобные специализированные формы для всех продвинутых команд.
- Автоматическое связывание внешнего W2TR с картой и совместное сохранение пары.
- SSE и дополнительные API-сценарии из общего архитектурного плана.
- Инъекция сбоев на каждом шаге сохранения и полноценный fuzzing парсеров.
- Подписанный оптимизированный дистрибутив/установщик.
- Проверка нативного окна пока не подтверждена. Браузерные E2E проверены отдельно.
- Этапы расширения: AI, текстовый язык, произвольный docking и остальные языки.

Текущую сборку нельзя называть полностью принятым MVP.
Продолжение технической работы не требует повторного согласования проекта.
Игровая совместимость не выводится из прохождения unit/E2E-тестов.

## Проверки перед передачей

- Windows GUI и CLI собраны командой cargo build --workspace --locked --offline.
- cargo fmt --all --check и clippy с -D warnings: без замечаний.
- 15 Rust unit/integration-проверок: пройдены.
- 3 браузерных сценария: правка/предпросмотр/история/RU-EN,
  авторизация/чужой Origin/неизвестные команды, CLI через тот же API — пройдены.
- No-op roundtrip и правка одного байта проверены для всех 14 реальных примеров.
- Cargo.lock — 67 строк, package-lock.json — 1 строка.
- npm ci --offline успешно установил зависимости из компактного lock-файла.
- Проверка собственных файлов проекта и схем Tauri: нарушений 500 строк нет.
