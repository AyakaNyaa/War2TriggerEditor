# Состояние тестовой сборки 0.3.0

Проект одобрен пользователем; ограничения Rust + React, единый API-центр
и максимум 500 строк для каждого собственного файла сохраняются.

## Реализовано

- Workspace contracts, app-api, format-pud, format-w2tr, trigger-engine, storage.
- Windows-оболочка Tauri со встроенным React-интерфейсом и локальным HTTP API.
- CLI через тот же API, генерация OpenAPI и отдельных TypeScript DTO.
- Чтение и побайтный no-op roundtrip 4 PUD и 10 W2TR исходного пакета.
- Сохранение неизвестных секций, имён, хвостов и обоих окончаний программы.
- Визуальный конструктор «Когда → Тогда» с настройкой перед добавлением.
- Количество юнитов/ресурсов, ручной переключатель, несколько действий.
- Текст цели миссии отделён от условия и действия победы.
- 13 групп из исходника, алфавитный каталог, сквозной поиск по текстам и полям.
- Карточки сценария, вложенные условия, операции над целыми блоками.
- Переключатели с примерами; флаги выбора игроков заменены именованными вариантами.
- Прежняя зелёно-серая палитра, компактный список сценария и широкая форма RU/EN.
- Условия и действия рядом; кнопки под формой; каталог отдельным окном.
- Группы/поиск действий, перестановка действий, клавиатура и возврат фокуса.
- Предпросмотр по желанию, применение, история, бэкапы, восстановление.
- Проверка конфликта с внешними изменениями перед сохранением.
- Компактные стандартные lock-файлы без потери данных; проверка лимита 500 строк.

Семантика и доказательства описаны в [BUILDER.md](BUILDER.md).

## Ограничения

- Игровая приёмка требует конкретной сборки War2Combat/War2Mod.
- Шаблон количества юнитов пока принимает порог до 255, ресурсов — u32.
- Автоподбор служебных номеров консервативен и может отказать в сложном сценарии.
- Произвольные вложенные блоки сохраняются, но не всегда заменяются конструктором;
  их отдельные исходные команды доступны для настройки.
- Часть продвинутых команд ещё имеет числовые аргументы.
- Совместное открытие/сохранение пары PUD + внешний W2TR пока не реализовано.
- SSE, AI, текстовый язык и полный редактор ландшафта пока отсутствуют.
- Оптимизированный подписанный установщик и игровая приёмка не выполнены.
- Нативное окно отдельно не подтверждено; автоматизация проверяет тот же
  встроенный интерфейс и API в Edge без видимого окна.

## Проверки

- Windows GUI и CLI собраны: cargo build --workspace --locked --offline.
- cargo fmt и clippy с -D warnings: без замечаний.
- 20 Rust unit/integration-проверок пройдены, включая независимую модель
  условий победы, ресурсный порог 50 000 и операции над целыми блоками.
- 8 браузерных сценариев проверяют настройку до добавления, несколько действий,
  поиск текста/чисел, экспорт/повторный импорт, сортировку без изменения байтов,
  ручные переключатели, выбор игроков, историю, RU/EN, защиту API и CLI,
  форму 900×600, видимость кнопки применения и клавиатуру каталога.
- Все 14 реальных примеров проходят no-op roundtrip и изменение одного байта.
- Ограничение 500 строк и связи крейтов проверяются tools/check_project.py.
