# Как скачать и запустить редактор

## Готовая Windows-сборка

1. Откройте [страницу тестового выпуска](https://github.com/AyakaNyaa/War2TriggerEditor/releases/tag/v0.1.0-preview.1).
2. В разделе Assets скачайте **War2TriggerEditor-preview.zip**.
   Архивы **Source code** предназначены для разработчиков, не для обычного запуска.
3. Распакуйте ZIP в отдельную папку через «Извлечь всё…».
4. Откройте распакованную папку и запустите **War2TriggerEditor.exe**.

Для запуска готового EXE устанавливать Rust, Node.js или Git не нужно.
Установка редактора в систему и права администратора не требуются.
Эта сборка предназначена для 64-битной Windows (x64).

## Если окно не открывается

Редактор использует Microsoft Edge WebView2 Runtime.
Если Windows сообщает, что этот компонент отсутствует, установите Runtime
с [официальной страницы Microsoft](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)
и повторно запустите редактор. Выберите вариант для Windows x64.
Не запускайте EXE прямо из открытого ZIP: сначала извлеките файлы.

## Первая правка

1. Нажмите «Открыть файл» и выберите карту **.pud** или триггеры **.w2tr**.
2. Выберите команду в центральном списке и измените её поля справа.
3. Нажмите «Просмотреть изменения», проверьте результат и примените правку.
4. Для первой проверки используйте «Сохранить как…» и новое имя файла.
   Перед записью редактор создаёт резервную копию.

Чтобы проверить интерфейс без карты, нажмите «Создать файл триггеров».
Русский/английский язык переключается справа вверху.
Для первого запуска самой игры наличие War2Combat не требуется.

## Что находится в архиве

| Файл | Назначение |
|---|---|
| War2TriggerEditor.exe | Редактор с окном |
| war2-cli.exe | Необязательный клиент для автоматизации |
| RUN_RU.md | Эта инструкция запуска |
| USER_GUIDE.md | Работа с триггерами, бэкапами и восстановлением |
| README-RU.txt | Краткое описание тестовой сборки |
| manifest.json | Размеры файлов и SHA-256 |

Это предварительный выпуск. Технические проверки пройдены,
но поведение сохранённых сценариев ещё нужно проверить в целевой сборке
War2Combat/War2Mod. AI, ручной язык и полный редактор ландшафта сюда не входят.
