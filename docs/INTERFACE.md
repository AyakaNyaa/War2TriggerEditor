# Компоновка и внешний вид

Принятое предпочтение пользователя: прежняя тёмная зелёно-серая палитра
с тёплым золотым акцентом. Синяя версия заменена по его просьбе.

- Слева — компактный список элементов текущего сценария.
- Справа — широкая форма выбранного элемента.
- Условия и действия расположены рядом, когда ширина окна позволяет.
- При небольшой ширине они переходят в одну колонку.
- Кнопки применения находятся под прокручиваемой областью формы,
  не накрывают поля и не уходят при прокрутке.
- Каталог открывается по запросу отдельным окном с группами и поиском.
- Каталог действия исключает неподходящие структурные команды и настройки до старта.
- Параметры открываются сразу при выборе команды.
- Описание действия показывается один раз, без дублирующего списка типов.
- Действия можно заменить, переставить и удалить прямо в форме.
- Дополнительные файловые операции находятся в меню «Ещё».
- Сообщение об успешном применении появляется в строке состояния
  и не перекрывает кнопки. Ошибки показываются отдельно.

Основные цвета определены в `apps/frontend/src/shared/theme.css`:
фон `#131716`, поверхность `#1b211c`, акцент `#c3a56b`, текст `#deded4`.
Основной шрифт — Segoe UI; подписи полей должны оставаться читаемыми.

Клавиатура: Ctrl+K — поиск, Ctrl+S — сохранение.
При открытии каталога фокус находится в поиске, стрелка вниз ведёт к результатам.
Esc закрывает окно и возвращает фокус на кнопку, которая его открыла.
Модальное окно удерживает фокус внутри себя.

Проверки интерфейса охватывают обычное окно и 900×600,
поиск/группы, порядок действий, сохранность экспорта и доступность основной кнопки.
