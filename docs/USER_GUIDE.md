# Быстрый старт

## Открыть и изменить

1. Запустите `War2TriggerEditor.exe` из распакованного выпуска.
   После самостоятельной сборки путь — `target/debug/war2-editor.exe`.
2. Нажмите «Открыть файл» и выберите PUD или W2TR.
   «Импорт файла» загружает копию без привязки к исходному пути;
   первое сохранение такой копии откроет диалог выбора места.
3. Выберите команду в центральном списке. Справа появятся её поля.
4. Измените значения, нажмите «Просмотреть изменения».
5. Проверьте, что именно изменится, и нажмите «Применить изменения».
6. Нажмите «Сохранить». Программа сначала создаст и проверит бэкап,
   затем запишет временный файл и заменит оригинал.

Изменения полей не считаются применёнными, пока вы не подтвердили предпросмотр.
Сохранение при неприменённых полях блокируется с пояснением.
При переходе к другой команде редактор спрашивает о сбросе таких полей.

## Пример на готовом файле

Откройте `legacy-audit/source/tr/ex/1.w2tr` через «Импорт файла».
Первая команда — установка значения. Измените поле «Значение» с 0 на 2,
просмотрите и примените изменение. «Отменить» вернёт 0, «Повторить» — 2.
Сохраните результат под новым именем через «Сохранить как…».
Имена переменных, находящиеся в служебной части W2TR, сохраняются побайтно.

Для первой игровой проверки используйте копию карты, не единственный оригинал.
Тесты редактора проверяют структуру и байты; поведение сценария проверяется в игре.

## Создать триггеры

Нажмите «Создать файл триггеров». Внизу списка выберите команду и добавьте её.
Для IF и Repeat автоматически добавляется закрывающая команда.
Далее измените поля и сохраните новый W2TR.

Удаление или перемещение, оставляющее незакрытое условие/цикл,
не применяется: редактор покажет ошибку проверки.
При смене операции со списком юнитов её аргументы сбрасываются на начальные;
новые значения видны в предпросмотре, затем их можно настроить.

## Бэкапы и восстановление

Рядом с сохранённым файлом создаётся каталог `.имя-файла.war2-backups`.
Путь к резервной копии показывается после сохранения.
При сохранении поверх другого существующего файла сохраняются и исходник,
и прежнее содержимое выбранного файла назначения.

Кнопка «Бэкапы файла» показывает доступные копии.
Восстановление заменяет файл на диске и текущее состояние редактора;
перед этим создаётся бэкап текущего файла. Требуется отдельное подтверждение.
Неприменённые и несохранённые правки текущего сеанса будут заменены.

После применённой правки также сохраняется отдельный снимок сеанса.
Обычно он находится в `%LOCALAPPDATA%/War2TriggerEditor/recovery`.
После перезапуска откройте «Снимки восстановления» и выберите нужный документ.
Восстановление сеанса само по себе не перезаписывает карту.
После успешного сохранения снимок этого сеанса удаляется.
Набранные, но ещё не применённые поля в снимок не входят.

Если карта изменена другой программой, запись останавливается.
Сохраните свои правки в другое место или заново откройте актуальный файл.

## Что нужно учитывать

- Неизвестные команды и неоднозначные данные открываются только для просмотра.
- Размер OILM не увеличивается автоматически. Если программа не помещается,
  запись блокируется; содержимое остальных секций не перестраивается.
- Расширение программы поверх неизвестного ненулевого хвоста OILM блокируется.
- Игровые строки редактируются в Windows-1251; неподдерживаемые символы
  отклоняются, а не заменяются знаками вопроса. Это предварительный профиль.
- В PUD нет имён переменных из W2TR. Сейчас файлы открываются отдельно;
  автоматическое объединение карты и внешнего проекта ещё не реализовано.
- AI-чат, ручной текстовый язык и полный редактор ландшафта пока отсутствуют.
- Проверка в конкретной сборке War2Combat/War2Mod ещё предстоит.
